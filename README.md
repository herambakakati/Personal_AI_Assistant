# 🤖 AI Personal Assistant

An AI-powered personal assistant built with Python, Streamlit, LangChain, and OpenAI GPT-4o-mini. It helps users manage everyday tasks through natural language conversations, making information access and task management simpler and more convenient.

## ✨ Features

- 🌤️ **Weather Updates** — Get weather forecasts for different locations.
- 💱 **Currency Converter** — Convert USD to INR using live exchange-rate information.
- 🕒 **Time & Date** — Get current date and time information.
- 🔔 **Smart Reminders** — Schedule reminders and retrieve pending reminders.
- 🌐 **Web Search** — Search for news, people, companies, technology, and other information.
- 🧮 **Math Assistant** — Calculate mathematical expressions and solve supported problems.
- 💬 **Natural Language Interaction** — Communicate with the assistant using everyday language.
- 🎨 **Modern User Interface** — Explore a custom Streamlit interface with a technology-themed background and conversational chat history.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Frontend:** Streamlit
- **AI Framework:** LangChain
- **Language Model:** OpenAI GPT-4o-mini
- **Web Search:** DuckDuckGo Search
- **Weather API:** Open-Meteo
- **Currency API:** Frankfurter
- **Reminder System:** Python datetime and threading
